# 07. Glosario y referencias

## 1. Glosario

- **Accuracy:** proporción de predicciones correctas respecto al total de predicciones realizadas.
- **Árbol de Decisión:** algoritmo de aprendizaje supervisado que utiliza condiciones para dividir los datos y asignar una clase.
- **Baseline:** modelo de referencia sencillo que permite comparar el desempeño de un modelo más elaborado.
- **Dataset:** conjunto organizado de datos utilizado para el análisis y entrenamiento de modelos.
- **F1-score:** media armónica entre Precision y Recall, que permite evaluar el equilibrio entre ambas métricas.
- **Falso negativo (FN):** caso que pertenece realmente a la clase positiva, pero que el modelo clasifica como negativo.
- **Falso positivo (FP):** caso que pertenece realmente a la clase negativa, pero que el modelo clasifica como positivo.
- **Machine Learning:** conjunto de técnicas que permiten a los sistemas identificar patrones y aprender a partir de datos.
- **Matriz de confusión:** tabla que compara las clases reales con las clases predichas por un modelo de clasificación.
- **Precision:** proporción de predicciones positivas que realmente pertenecen a la clase positiva.
- **Recall:** proporción de casos positivos reales que el modelo identifica correctamente.
- **Sobreajuste:** situación en la que un modelo aprende demasiado los patrones específicos de los datos de entrenamiento y pierde capacidad de generalización.
- **Variable objetivo:** característica que el modelo intenta predecir.
- **Variables predictoras:** características utilizadas por el modelo para realizar sus predicciones.
